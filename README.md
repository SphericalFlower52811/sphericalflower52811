## Projects

### EndpointScanner

EndpointScanner is a website reconnaissance tool that scans for endpoints/directories/paths on websites.
Features of EndpointScanner:

- Performs accurate reconnaissance on **both** traditional websites and SPAs with little to no false positives
- Can scan **both** domains and IP addresses on the web (for example, it can scan example.com and 127.0.0.1:8080)
- Has a built-in fully customisable rate limit tester for the target website. (Customisable target endpoint, HTTP method, request headers, request body. Includes an iterable variable that can be defined in the body payload)

More details are mentioned in the documentation, and the source code can be found at the repo.

[EndpointScanner Docs](https://sphericalflower52811.github.io/endpointscanner/) | [EndpointScanner Repo](https://github.com/SphericalFlower52811/endpointscanner)
